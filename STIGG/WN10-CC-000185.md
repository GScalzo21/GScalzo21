# Remediation for WN10-CC-000185: Disable AutoRun Command Execution

## Step 1: Identify the STIG Requirement
- **STIG ID**: WN10-CC-000185
- **Requirement**: Disable AutoRun commands to prevent malicious programs from automatically executing when a removable drive is connected.
- **STIG Description**: AutoRun can allow potentially harmful executable files to run automatically, so disabling this feature enhances system security.

## Step 2: Check the Current Configuration
- Before remediating, check the current system configuration to see if the AutoRun feature is enabled or disabled.
- The relevant registry key is `HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\Explorer\NoAutorun`.
- You can check this registry key using PowerShell:

```powershell
Get-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\Explorer" -Name NoAutorun

If the value is 0, AutoRun is enabled; if it's 1, AutoRun is disabled.
Step 3: Verify the System Version

Ensure you are working on a Windows 10 system, as this remediation applies specifically to Windows 10 operating systems.
Step 4: Modify the Registry Key

You need to modify the registry key to disable AutoRun. The registry value NoAutorun needs to be set to 1 to disable AutoRun commands.
Registry Path: HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\Explorer
Value Name: NoAutorun
Value Data: 1 (This disables AutoRun)
Step 5: Update the Registry

PowerShell Command to Modify the Registry:

$registryPath = "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\Explorer"
$valueName = "NoAutorun"
$valueData = 1

# Ensure the registry path exists
if (-not (Test-Path $registryPath)) {
    New-Item -Path $registryPath -Force | Out-Null
}

# Set the registry key to disable AutoRun
Set-ItemProperty -Path $registryPath -Name $valueName -Value $valueData -Type DWord
Write-Host "AutoRun command execution disabled (NoAutorun = $valueData) at $registryPath"

This script checks if the registry path exists, creates it if necessary, and sets the NoAutorun registry key to 1 to disable AutoRun.
Step 6: Verify the Change

After running the script, verify that the registry value has been correctly set:

Get-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\Explorer" -Name NoAutorun


The output should show the value 1, confirming that AutoRun is disabled.
Step 7: Test the Configuration

Test the system by connecting a removable device, such as a USB drive, to ensure that AutoRun does not automatically execute any programs.
Check the system's behavior and ensure that it complies with security best practices.
Step 8: Document the Remediation

Keep a record of the remediation steps, including the script and any changes made to the system, for future reference and auditing.
The remediation should be documented in your security policies or as part of a system audit.
